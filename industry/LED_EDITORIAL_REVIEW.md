# LED 新闻编辑规则：待校准草稿

这次改动让现有预筛、写作、翻译和事件综述理解 LED 显示行业，减少把部件消息写错、把厂商宣传升级成结论、把外部能力归给齐普的风险。资讯入口继续以阅读与回访为目标，新闻没有采购建议或 CTA 也可以有价值。

## 本次已接入的行为

- 预筛覆盖灯珠/封装/芯片、驱动 IC、电源、控制系统、材料、工艺设备和真实应用。通用照明等消息按实际显示相关性判断，不按厂商名整批放行。
- 五个评分维度、七个类型 key、类型权重、信源阈值与调用结构保持原样；改的是读者、价值与噪声的例子。新闻价值不以能否询盘为前提。
- 共用 `rules-led-evidence.md` 进入已有摘要、内容理解、全文翻译和综述提示词；结构抽取优先保留型号、供货阶段、测量条件与例外的原文句子。
- 增加 Chipshow、NovaStar、Nationstar、Kinglight、Macroblock、MEAN WELL、Daktronics 身份词条。沿用已有 `enforceIdentity`：凭空加入已识别公司时回退标题或丢弃摘要。保留旧词条以免破坏历史记录与既有测试。
- 官方域名只加入本轮核验的 `novastar.tech`、`nationstar.com`、`kinglight.com`、`mblock.com.tw`、`meanwell.com`、`daktronics.com`；未核验 Chipshow 域名，因此没有补它的发布方映射。

## 不能据此宣布已完成的工作

这是供 PR 审阅与离线试验的行业编辑规则，不是完整 LED 站，也不是已校准的编辑能力。

1. 原类别 key 和主题目录保留兼容，LED 产品暂沿用 `ai-products`，通用内容沿用 `industry/paper/tip/opinion`。站点名称、AI 示例页面文案、主题导航与品牌仍要在单独的站点迁移任务中处理；当前草稿不应作为完整行业站直接上线。
2. `industry/selection.ts` 未改。当前门槛来自上游示例站，要按 `docs/customize.md` 用 100–200 条真实、人工标注的 LED 样本做首轮校准。`led-editorial.examples.json` 全是合成材料，用来讨论边界，不能当成真实消息、真实工程数据或质量得分。
3. 提示词要求不等于程序已经验证。本 PR 依赖独立的完整摘要保留修复，避免在持久化前机械截掉后句条件；该修复不验证模型原稿是否正确。翻译数字/限定词校验，以及“公司都在原文但参数归错对象”等问题仍需行为级改进与真实样本评测。身份词典只防部分凭空加入公司，不验证每条参数所属型号。部分中文简称（如普通动词“聚积”）有歧义，本轮采用正式品牌名与经核验的域名确定归属，避免把普通词当成公司；人工审稿仍须检查简称与参数所属对象。
4. 当前 main 的模块注册为空，没有可核对的私有新闻 Hub 源码。**中文审核、英文发布、960×720 封面、精确版本批准、WordPress 人工编辑保护**均须恢复原 Hub 源码后继续接入；本改动没有实现或验证这些流程。
5. 本改动不注册信源、不改采集开关、不调用真实模型、不连生产数据库、不写 WordPress。没有稳定采编、上线、流量或 GEO 收益证据。

## 审稿时看六件事

| 看到什么 | 稿件应怎样写 |
|---|---|
| 原厂宣布或声称效果 | 写明主体与阶段；效果仍归于厂商及其条件 |
| 峰值/平均、模组/整机、AC/DC | 保持测量对象与口径，不擅自互换或算节省比例 |
| 特定子型号、测试环境、例外 | 和对应数字在同一句出现；篇幅不够时少报一项数字 |
| 样品预计、试产、量产、停产 | 保留原阶段，预计日期不能写成已发生 |
| 合作厂商、部件或竞品参数 | 归于原对象，不转成齐普自己的产品承诺 |
| 目录、旧规格书、页面改版 | 先确认本次新增动作，不能因今天抓到就当新产品发布 |
