0. 这一轮要解决什么
v1 跑通了“命题 → 脱敏 → 备料 → 确认 → 建任务”，但还交不出可用的升级稿。原因有三个：找到的证据大多答不了问题；升级稿没有说清比旧页多了什么；成稿要求模型一次写完整页的中英文，结果超时。本轮只解决这三件事，并以真实的尺寸指南（WP 文章 6098）作为唯一验收用例。
1. 审校结论
保留的做法（v1 已经做对）：


* 保存前强制脱敏；同题、同页去重；证据不足时不进第二段调用。
* 出处必须是原文里的逐字句子；工程题的 A 选项必须是不含数字的保守写法。
* 已保存的模型回答可以免费重放；结果未知的调用不自动重试；CI 全绿。

2. 三个设计答复
2.1 证据：从“关键词相关”到“能回答子问题”
1. 先拆题。 第一段调用（原“抽关键词”，不新增调用）改为输出 3–6 个买家子问题。每个子问题带四项：中英文问法；需要哪类依据（旧页、参考资料、代码计算、公司事实、新闻）；答案形态（数字、表格、定义、步骤）；2–4 个只属于这个子问题的检索词。
2. 按子问题、按句子检索（代码完成，不调用模型）。 先用现有 SQL 粗筛最多 50 篇；再把正文切成句子，给每个子问题打分。同一句里出现 ≥2 个该子问题的检索词，并且符合答案形态（例如数字题要带“数字＋单位”），才算答案句。每个子问题取前 2 句，各带前后 1 句作上下文。
3. 折叠弱相关。 没有任何答案句的素材默认折叠，显示为“弱相关 N 条”，运营可以展开。
4. 算出来的不交给模型。 像素数、英尺和米的换算（1 ft = 0.3048 m，按定义精确）、画面比例对比，由代码函数计算，作为“计算事实”入表；模型只负责把它写成句子。
5. 补一个参考资料源。 为前 10 个常青页主题，登记 10–15 个权威参考页面（标准组织、行业协会、计量机构），走现有的链接抽取进素材池，信源名为“参考资料”，不受短讯的新鲜度窗口限制。清单写进 LIVE.md，你可以删改。
6. 缺口给出明确的补料方式。 没有依据的子问题标为“缺”，并写明缺哪类依据（例如“需要参考资料：标准广告牌尺寸”）。运营贴一个链接后，只重跑这一个子问题的检索。
2.2 旧页升级：先找差距，再动笔
1. 把旧页切段。 代码把旧页正文按标题和段落切成 p1…pn，保存段落原文和 HTML。
2. 逐个子问题判断覆盖情况。 在第二段调用里判断：旧页已答好（引用段落编号）／旧页答得弱（写明原因：过时、不清楚、缺数字、缺步骤）／旧页没答。
3. 用需求信号排序。 已导入的 GSC 或 Semrush 数据里，这个 URL 的查询词按检索词归到子问题，附上曝光和排名；询盘问题同样归入。没有数据时写“无需求数据”，不编造。
4. 输出编辑计划，不输出整篇。 计划里只有三种操作：keep（保留，默认，不需要理由）；revise（改写某段，必须写明理由和对应的子问题）；insert_after（在某段后新增一节，必须写明子问题和理由）。改写的段落不超过全部段落的 30%。没有缺口时，结论是“无需升级”，这也是有效结果。
5. 运营看到的是“这次补了什么”。 编辑计划逐条列出：补上了哪个买家问题、依据是什么、需求信号是什么。尺寸指南这个例子里，旧页已有的标准尺寸表、调查和许可段落都应标为 keep，在拼装后的整页里逐字不变。
2.3 成稿：只写改动片段，由代码拼装
1. 一个改动，一次调用。 每个 revise 或 insert_after 各调用一次模型，最多 2 个并发，单次超时 90 秒。
2. 每次调用的输入只有这些： 改动类型和标题；改写时附上目标段落，以及前后各一段（各不超过 600 字符）；该子问题的英文问法；不超过 6 条事实（陈述、≤300 字符的逐字引文、出处、日期、归属类型）；相关的工程答案；一张固定的规则卡（≤1,200 token：归属写法、不许出现事实表以外的数字、单位写法、语气、禁用词、保守写法规则）；输出格式。不附原文全文。 只有当某条引文太短、撑不住要写的句子时，才补该出处的前后两句。
3. 输出： 英文 HTML 片段、这一片段的中文审校稿、实际用到的事实编号。中文只写改动部分，不翻译整页。
4. 代码校验每个片段： 片段里的数字都必须能在所用事实或计算结果里找到（统一单位后比较）；所用事实编号必须属于本次提供的范围；改写长度不超过原段的 2 倍；新增一节不超过 250 词。
5. 代码拼装整页： keep 的段落原样放回，逐字节不变；改动片段放到对应位置；同时生成新旧对比视图，供运营审稿。编辑门只检查改动片段，数字一致性检查覆盖整页。
6. 结果未知的处理： 某个片段超时，只标记这一个片段为“结果待核对”，其他片段照常保存；运营可以单独重试这一个片段，系统不会自动重试。
7. 新长文也走同一条路： 大纲的每一节都看作在空白页上的 insert_after。

预算：本轮真实模型调用最多两次备料、一次按片段的完整成稿、一次测试调用；其余一律用已保存的回答重放。结果未知的调用不自动重试，记录后继续做其他部分。
