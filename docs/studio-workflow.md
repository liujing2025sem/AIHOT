# Studio 日常使用

本轮按用户要求使用统一管理员。登录后进入 /admin/studio；API配置在 /admin/channels。分角色权限暂缓。

1. 素材池默认展示正文可读的材料；可切换全部、待补正文、待核发布日期。标题进入原文阅读页，支持补采正文。不会把采集时间当发布日期。
2. 勾选1–12条材料，指定可选目标页面，创建采编任务。目标站点限Chipshow主站/美国站/欧洲站及Unishine。空目标按中立行业资讯。
3. 可下载单文件JSON交给Codex/Harness，内容包括原文版本、human-writing与公司规则、返回格式。将返回JSON导入相应任务，稿件写入数据库。重复导入同一结果不覆盖人工修改；原文版本变化时拒绝旧结果。
4. 也可点击“通过API成稿”（最多4条）。服务端读取当前渠道，通过原有预算和回执调用模型，校验引用后存为草稿。当前OpenCode Go只适用于编码；新闻生成需配置DeepSeek标准API或适合的兼容渠道。没有密钥/开关关闭时显示原因，不产生假稿。
5. 中文审稿、英文交付、原文证据、修改记录通过标签切换。保存使用版本检查，其他人已修改会提示刷新；保存已审核稿会撤销旧批准。切页/关页前提醒未保存修改。
6. 提交审稿→确认审核通过，或填写意见退回。审核通过可导出Markdown、HTML、JSON。这里的通过和导出不会自动发到公司官网。
7. 采集信源中可手动采集、查看错误、进入原生信源设置或新增来源。网络超时保留原材料与错误，不伪造新增。自动worker本轮未启用。

API配置保存到settings表；密钥在本机模型凭据文件。API生成开关实时读取持久化文件，独立进程可见。配置检测采用实际/models响应，404明确显示不支持列表；付费测试须由管理员明确点击。DeepSeek Pro禁用。

Windows运行包包含Node、PostgreSQL、安装依赖、源码、构建及初始化程序；不包含个人密码、API密钥、活动库和旧会话。安装默认本机访问，预置三个暂停自动采集的真实LED信源。移机操作见studio-deployment.md。

本轮验证：真实两篇Codex稿导入；网页保存/送审/退回；跨版本冲突与重复导入；API实际向指定本地服务发请求并持久化稿件；真实OpenCode模型列表返回404；另一目录和独立端口完成安装、启动、登录与私有数据恢复。第二台物理电脑和外网发布未执行。
