# Chipshow Studio React 编辑台更新包

版本：2026-11-09。对应 AIHOT 项目 PR #21。

## 你拿到什么

这是完整工程更新包，包含真实前后端源码、锁定依赖清单和已经编译的网页。更新到现有 AIHOT 后继续使用原来的稿件、账号、素材与私有配置。

本包适用于已有运行环境的升级，未包含 Windows Node/PostgreSQL 二进制及平台依赖。新电脑需要先准备运行环境。网页需要服务端，不能双击 build 目录里的文件使用。

## 这次操作界面怎么变了

| 你要做什么 | 入口与反馈 |
| --- | --- |
| 从现有材料里挑文章 | 左侧「今日选稿」，勾选带来源和日期的材料卡 |
| 看选完后能做什么 | 页面底部自动出现已选数量与下一步按钮 |
| 围绕买家问题做专业文章 | 左侧「专业内容」，接现有命题采编 |
| 接着审已有稿件 | 「继续审稿」或「我的稿件」，无需重新生成 |
| 核对问题 | 正文旁查看待确认项，展开出处，定位原句 |
| 查看英文或证据 | 审稿页切换中文、英文、原始证据 |
| 发到 WordPress | 沿用现有稿件的草稿推送或已授权的一键上线模式 |

设置、运行和信源管理放进次级入口。手机使用抽屉导航。

## 下载以后

1. 完整解压到一个新目录，保留原 AIHOT 安装目录。
2. 维护人在现有运行环境按 `DEPLOYMENT.md` 更新。更新包括新增组件依赖，单独替换网页文件不完整。
3. 启动后打开原来的 Studio 地址，先进入已有 6098 待审稿核对。已有稿件无需再生成。

本包不会自行更换你正在使用的版本，也不会打开采集、付费模型或发布开关。目标机尚未安装验收。

## 需要明确的功能范围

- 组件库已经换为 Radix UI React 交互组件，采用 shadcn/ui 风格源码组织和 Lucide 图标。
- 已有后台流程和权限保留。本次主要完成选稿、导航与审稿界面的改写。
- 当前最多选择 12 条材料；既有自动成稿一次最多处理 4 条，按材料生成稿件。
- **多条新闻合成一期短讯仍待接通。** 本包没有把这个未完成能力写成已交付。
- 真实采集与模型是否可用取决于现有配置。封包不附私人密钥、业务数据库或公司黑名单。
- 完整测试结果见封包旁的 `verification.json`。自动测试通过与运营实际的一分钟易用性测试分开记录。
