# AIHOT 英文采编工作台

登录后打开 `/admin/workbench`。首页优先给出待处理的原稿；只有已保存选题时，直接从原选题继续。选题、稿件和工作台随时可达。发布记录、处理进度和信源管理在管理与工具中。

1. **选题**。选择新闻材料，或点“写下买家问题”。检查客户信息、选择资料和文章范围，确认方向后再生成。
2. **审稿**。默认查看英文，中文摘要提示要核对什么。旧页升级可定位有依据的原段和修改片段。保存核对、请 AI 修改、人工批准各有独立按钮。离开未保存正文时，可保存、放弃或继续编辑。
3. **配图与交付**。批准正文后可选封面，也可直接进入交付。确认当前成品，再下载绑定该版本的英文交付包。WordPress 操作由实例现有设置控制。

当前源码、构建和安装说明随包提供。源码入口为 `source/README.md`，运行状态与真实稿件顺序见 `source/docs/LIVE.md`。对应变更见 [PR #28](https://github.com/liujing2025sem/AIHOT/pull/28)。
