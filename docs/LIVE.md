## 决定（2026-11-08）

| # | 决定 |
|---|---|
| D-01 | AIHOT 只推 WordPress 草稿（REST 加应用密码），由用户点发布；短讯是 Blog 下的一个栏目 |
| D-02 | 官网只发英文源页面，多语言由用户的翻译插件生成；中文稿只做内部审校 |
| D-03 | 短讯和短文章：流量优先、时效次之；标题冲击力优先，但每个钩子都要有事实锚点 |
| D-04 | 长文：质量优先；一篇解决一个真实询盘问题；长期维护；给销售的定制版以后再做 |
| D-05 | 泛流量范围：公共场景的 LED 屏、上下游产业链、相邻行业（DOOH、数字标牌、AV、虚拟拍摄）、消费级显示 |
| D-06 | 原创素材来自：询盘里的真实问题、工程师每月审稿答疑、项目案例和现场照片 |
| D-07 | 短讯按量出刊：每攒够 5 条可用素材出一期；不设日历、跳刊和补刊规则 |
| D-08 | Codex 负责合并，条件是 CI 通过且有本项的真实样例证据；Claude 每周抽样审校 |
| D-09 | 风险清单 v2：同行负面、自家负面、贬损齐普的内容一律不写 |
| D-10 | 短讯栏目名默认为“LED Display Brief”，用户可以改 |

## 底线

- **G1 公开的就是批准的。** WP 草稿内容就是 Studio 里批准的英文版本；改过就要重新批准。
- **G2 数字有出处。** 数字、型号、条件都带来源，写在文中或表格的来源列；厂商的说法标为厂商说法。BLOCK 不放宽。
- **G3 新闻是新的。** 没有原文日期或超过 7 天的素材不进短讯；同一事件只出一条。
- **G4 风险清单 v2。** 见 D-09。
- **G5 不越界。** 不绕过 403、429、验证码和登录；不提交密钥和私有数据；AIHOT 不对公网开放；WP 只建草稿。
